## 標題
離線 ISO 27001 合規顧問 Agent：用五道自動關卡讓 AI 誠實

## 影片
https://youtu.be/7TvK1gugw_k

## 摘要
這是一套 100% 離線運行的 ISO 27001 合規顧問 Agent。核心是「AI 生成、程式把關」的品質方法論：知識圖譜靠五道自動關卡過濾 AI 幻覺，混合檢索靠信心閘門避免語意融合稀釋精準規則，並用改寫題評估集戳破過擬合的假滿分。專案也修復了真實使用者回報的推理錯誤，並寫入永久回歸測試。

## 建構理念（Why I built this）
我選擇打造離線版 ISO 27001 合規顧問 Agent，因為資安合規顧問服務昂貴且仰賴個人經驗，而 ISO 27001 條文本身是公開、結構化的知識，正是 RAG Agent 最適合切入的場景。合規工作常牽涉企業機敏文件，因此我從一開始就把「100% 可離線運行」設為硬約束，而非事後補強的選配功能。

最大的挑戰不是把系統做出來，而是**發現它其實沒有真正做出來**。專案曾宣稱具備 Hybrid Search 與知識圖譜檢索，但盤點後發現這些產物早因缺乏版控而遺失。這讓我設計了一套「AI 提名、程式把關」的建置流程：LLM 提名候選關聯邊，依序通過結構規則、引文字串比對、語意相似度、雙向一致性、六十題評估回歸共五道自動關卡，全數通過才能進圖譜。背後哲學是：生成器可以犯錯，但驗證器必須是確定性程式邏輯，而非另一個會唬爛的 AI。

這套關卡隨即發揮作用。正式評測顯示本地 12B 模型的引文誠實率僅 12.73%，我因此封存 LLM 提名產線，改用專案既有的人工關聯圖直建知識圖譜。接上混合檢索後，期末評估準確率不升反降——消融實驗揪出根因：等權融合稀釋了人工調校的高信心關鍵字規則。於是我設計「信心閘門」：規則有把握時直接採用，沒把握才交給向量與圖譜。為驗證此設計不是又一次過擬合，我另建改寫題評估集，用不同措辭重問。結果原題庫的滿分其實是假象，換句話說的問法讓命中率驟降近三成，信心閘門模式在真實情境下全面勝出。

上線後，一位使用者回報多選題被誤判為單選，且系統編造了排除選項的理由。追查後發現，干擾選項意外觸發關鍵字加權，把正解擠出檢索範圍。我修復了偵測邏輯與檢索策略，並將此案例寫入永久回歸測試——這印證了整個專案的核心方法論：任何斷言背後都必須有可驗證的證據，而非等待被信任。
