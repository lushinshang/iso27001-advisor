## 01:20–02:20｜核心設計思路：AI 生成、程式把關（畫面：SDD HTML 的五道關卡資訊圖）

**講稿**：
「這個專案真正的核心不是問答本身，而是一套『AI 生成、程式把關』的品質方法論。舉個例子：我想幫系統建一個知識圖譜，讓相關條文能互相關聯。一開始的做法是讓本地 LLM 自己判斷哪些條文相關，但正式測試後發現，AI 引用原文的誠實率只有 12.73%——它會編造根本不存在的句子。」

**畫面動作**：切到 `docs/specs/kg_hybrid_search_sdd.html`，展示「五道自動品管關卡」資訊圖，滑鼠依序點過 G1–G5。

**講稿（接續）**：
「所以我設計了五道自動關卡：結構規則、引文字串比對——就是直接檢查 AI 說的那句話是不是真的存在於原文——語意相似度、雙向一致性，最後是六十題評估回歸。AI 可以犯錯，但把關的是確定性程式邏輯，不是另一個會唬爛的 AI。」
