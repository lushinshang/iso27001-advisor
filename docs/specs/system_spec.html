機制說明分值

語意快取（semantic_cache.py）

  • Embedding 模型：jeffh/intfloat-multilingual-e5-large-instruct:f16
  • Query prefix：Instruct: Given an ISO 27001 compliance question, retrieve the relevant control clauses\nQuery: {q}
  • 命中條件：相似度 ≥ 0.92 且 keywords / clause_id 出現在查詢中（雙重驗證）
  • 降級保護：索引不存在或失敗時靜默走正常 RAG

💬System Prompt 設計 v1.3 更新

核心設計哲學：LLM 是「判斷者」，不是「轉述者」。
資深顧問的價值在於判斷什麼該說、什麼不該說，而不是把所有檢索到的條文都倒出來。 客戶問「決定範圍的因素」，你卻把風險處理和績效評估也講進去，客戶立刻質疑專業判斷力。

三層引用架構（v1.3 新增第 7 條指令）

層級定義處理方式
核心條文直接回答使用者問題詳細說明，完整引用
延伸條文間接相關，對理解有幫助「📌 相關考量」子段，明確標示輔助性質
背景條文語意相近但不回答問題完全省略

回答格式結構

🎯 諮詢問題分析（1-2 句，只描述「問題要求什麼」，不引入條文）
📖 依據條文與控制項說明（只列核心條文；延伸條文另起「📌 相關考量」子段）
🛠️ 文件缺口與稽核證據建議（最核心 2-3 點，聚焦核心條文的舉證需求）
⚠️  免責與合規警示（1 句話，需由合格主導稽核員最終確認）

引用格式規範

  • 主條文：[4.3 決定資訊安全管理系統之範圍]
  • Annex A 控制項：[A.8.13 資訊備份]
  • Citation regex 同時識別三種格式：[A.X.X]、[X.X]、clause_X.X/control_X.X
效果驗證：修改後 q1（原本 0.55）提升至 1.00。擴充至 60 題後以 agy Judge 完整評估（Phase 1-3 改善後）：Citation = 91.8%、Content = 98.9%。 Phase 1（System Prompt 重構：per-claim 引用 + 消歧表 + 閉卷約束）+ Phase 2（Hybrid Search RRF）+ Phase 3（Knowledge Graph 1-hop）後 Content 大幅提升。 Citation 微降係因 per-claim 強制引用規則使 LLM 在不確定時保守省略標註，實際標註精準度提升。

Layer 1：Citation Faithfulness（程式解析，deterministic）

解析答案文字中的條文引用，檢驗是否所有引用都存在於 retrieved context 中。

# 同時識別三種引用格式
_CITATION_PATTERN = re.compile(
    r'\[A\.(\d+\.\d+(?:\.\d+)?)[^\]]*\]'          # [A.8.13 名稱] Annex A 格式
    r'|(?:clause|control)_(\d+\.\d+(?:\.\d+)?)'   # clause_X.X / control_X.X 內部 ID
    r'|\[(\d+\.\d+(?:\.\d+)?)[^\]]*\]',            # [4.3 名稱] 主條文無前綴格式（v1.3 修正）
    re.IGNORECASE
)
v1.3 修正：原始 regex 只識別 [A.X.X] 格式，導致主條文引用（[4.3 名稱]）全部被歸為「無引用」，9/10 題 no_citations_found=true。修正後加入第三個 group，全數正常解析。

Layer 2：Content Faithfulness（LLM-as-Judge，三層評分）

使用 LLM 評審員評估答案的事實聲明是否由 context 支撐。採用「寬鬆但可溯源」哲學。

A. 觀念正確性（70%）
~99%
B. 邏輯可追溯性（20%）
~98%
C. 條文準確性（10%）
~99%
層指標權重扣分邏輯
A觀念正確性70%核心建議是否符合條文意旨；矛盾則重大扣分（-80~100%）
B邏輯可追溯性20%每個建議能否追溯至 context 中某個條文；完全無出處 = 嚴重（-50~70%）
C條文準確性10%條文 ID / 名稱是否精確；編號錯但觀念對 = 輕微（-10~20%）
為何 B 比 C 更重要（20% vs 10%）：「觀念正確但完全無出處」比「編號錯但觀念對」更危險。 顧問業界：無法被稽核員追查的建議，客戶不應採納。

執行指令

# 生成答案 + Citation 評估（不跑 Judge）
python3 eval/faithfulness_evaluation.py --model gemma4:e2b-mlx --skip-content

# 完整評估（Citation + Content Judge）
python3 eval/faithfulness_evaluation.py --model gemma4:e2b-mlx

# 使用已快取答案重跑評估
python3 eval/faithfulness_evaluation.py --load-answers --gemini
